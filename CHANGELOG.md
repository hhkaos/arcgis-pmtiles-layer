# Changelog

## [Unreleased]

### Added

- ArcGIS Search, an optional public Living Atlas attractions layer with authored
  popups, and an optional Sketch toolbar with temporary drawings.

- GitHub repository link in the demo and README.
- Static GitHub Pages deployment workflow with a verified regional sample.

### Changed

- Translate the interface, SDK controls, number formatting and error messages to English.
- Read the worldwide archive directly from the public Protomaps mirror on Source
  Cooperative, which supports HTTP Range and CORS. No backend is needed for the
  static demo; the original Python range proxy remains available for local experiments.
